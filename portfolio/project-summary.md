# Project summary / プロジェクト概要 / 项目概要

## English

**VR-Embodied-AI-Companion — Embodied AI Companion with Agent Harness for VR Exercise Research**

Built an engineering prototype connecting a Unity XR character to an AI Backend through immutable state snapshots, context validation, a capability registry, native tool calling and explicit ToolResult feedback. Integrated observable turn/cancellation ownership, bounded recovery and evaluation, plus streaming LLM/TTS, LipSync, spatial voice, Gaze and spatial behavior.

The research direction combines preliminary Visual Gain with embodied interaction for future state-dependent, safety-constrained support selection. ExerciseInput, adaptive intervention research, long-term memory and proactive behavior are planned. Desktop test scopes and partial Quest evidence are distinguished: first-attempt microphone reliability fails, interruption3/5, stationary spatial outcomes partial, frame budget not met. No Android success or exercise efficacy is claimed.

Relevant roles: Game AI Engineer (state/action contracts and embodied behavior); AI Agent Engineer (context/tools/reliability/evaluation); Unity/XR Engineer (voice/avatar/input/platform integration). Developed with AI-assisted tooling; do not imply sole manual authorship of every line or ownership of third-party assets.

## 日本語

Unity XRのキャラクターとAI Backendを、State Snapshot・Context検証・Capability Registry・Native Tool Calling・ToolResultで接続するプロトタイプを構築しました。ターン管理、キャンセル、限定的フォールバック、評価基盤を整備し、Streaming LLM/TTS、口パク、3D音声、Gaze、空間行動を統合しました。

研究目標はVisual Gainの初期機能と身体性AIを組み合わせ、ユーザー状態に応じて安全な支援を選ぶことです。運動入力・適応的介入の効果検証・長期記憶・自発行動は未実装。Quest PCVRはPARTIALで、発話開始検出・割り込み3/5・静止時位置変更・フレーム予算に課題があります。Android実績や運動効果の実証は主張しません。

Game AI／AI Agent／Unity XR職向けに、状態と行動の境界、検証可能性、実機課題の透明性を示します。AI支援開発を用いており、外部モデル・SDK・素材を自身の制作物として扱いません。

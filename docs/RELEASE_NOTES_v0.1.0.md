# VR Embodied AI Companion v0.1.0

Source-code Showcase + Architecture Reference with a real Desktop interaction demo; not a turnkey Unity distribution or fully accepted Quest product.

- **Agent Harness:** authoritative state observations, immutable snapshots and bounded context.
- **Native Tool Calling:** availability/identity/argument checks, Unity dispatch through BehaviorOrchestrator and ToolResult feedback. New footage records real auto-selected Lead and Wave, not Debug calls.
- **Realtime Voice:** Japanese production complete-WAV ASR architecture, streaming DeepSeek/Roxy3, speech ownership/cancellation and history protection. The Demo uses preset Japanese text, not physical ASR.
- **Avatar:** expressions, Gaze, separate Walk/Run, Side/Lead spatial behavior and live LipSync; VoiceAnchor source audio.
- **Evaluation/Reliability:** fresh public contracts68 PASS/11 SKIP; skipped/live/platform gates remain unverified.
- **Desktop Demo:**66.87s,1280×720,15fps,H.264/AAC; same continuous Play, actual Japanese input/reply captions, virtual movement disclosed; no historical video/audio reused.
- **Research vision:** preliminary Visual Gain and future adaptive selection of exercise-support interventions. Gain is not active in this Demo; no sensor connection or efficacy claim.

## Known limitations

Quest PCVR remains PARTIAL; microphone detection/barge-in/performance issues are not cleared by Desktop footage. Android Standalone, exercise sensors, adaptive Gain Tool and exercise efficacy are unverified/not implemented. Wave currently precedes its speech by approximately2.67s. Source-level audio capture is not a complete spatial/HRTF mixer recording.
